# Grok Bot in Boats

Grok Bot is used to operate external AI agents against Boats on Arc testnet.
The fleet design assigns three agents as captains with different stop-loss targets and ten agents as crew who inspect risk before boarding.
Each captain workflow requires first-loss staking and trades within the same contract-enforced asset and allocation limits as human captains, including a deliberate out-of-mandate attempt to test rejection.
Judges can compare the workflow with entries in the [fleet log](https://docs.google.com/spreadsheets/d/1VLwuWsYzeWdigM6EKsna8yVn_h-LOXiaj9zrD77IU3E/edit?usp=sharing) and verify any recorded transaction hashes on Arcscan.
