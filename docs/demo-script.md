Use the current [2:45 recording script in the Devpost draft](devpost.md#demo-video-script-245). It is the canonical script; the older hypothetical live flow has been retired.

Prepare two read-only terminal results: `npm run verify:agent` (eight synthetic scenarios, no network) and `npm run verify:proof` (five historical Arc proofs, no signer). Show the deployed mandate, Gemini decision memo, rejected overweight swap and completed crew payout.

The historical evidence spans two boats. Mock prices were changed manually for the settlement test; the payout is not real investment performance. Production passkey onboarding must be verified interactively before it appears as a successful step in the recording.

Use existing explorer evidence if the testnet is slow. The [partner research](partner-research.md) explains the narrative, sponsor fit and questions to prepare.
